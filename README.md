# GranVremeni — Каталог памятников и изделий из натурального камня

**GranVremeni** — веб-проект для представления и продажи памятников, мемориальных изделий и натурального камня. Проект включает каталог продукции, страницы товаров, корзину и административную часть для работы с содержимым сайта.

🌐 **Сайт:** [Открыть GranVremeni](https://cheech1ko.github.io/GranVremeni/)

## О проекте

Цель проекта — предоставить клиентам удобный способ изучать памятники и изделия из камня, знакомиться с характеристиками материалов и выбирать подходящую продукцию.

В дальнейшем планируется интеграция искусственного интеллекта для автоматизации работы с каталогом, генерации описаний товаров и улучшения поиска.

## Основные возможности

- Каталог памятников и изделий из натурального камня.
- Страницы товаров с фотографиями и описаниями.
- Разделение продукции по категориям.
- Корзина для работы с выбранными товарами.
- Административный раздел.
- Отправка заявок и работа с формами обратной связи.
- Адаптация интерфейса для различных устройств.

## Планируемые AI-возможности

- **AI Product Description Generator** — генерация описаний памятников и товаров по заданным характеристикам.
- **AI SEO Assistant** — создание SEO-заголовков, метаописаний и ключевых фраз.
- **AI Catalog Assistant** — помощь администратору при заполнении карточек продукции.
- **Smart Product Search** — поиск товаров по запросам на естественном языке.
- **AI Product Recommendations** — подбор изделий по материалу, цвету, форме, размерам и бюджету.
- **AI Customer Assistant** — ответы на вопросы клиентов о продукции и материалах.

Все AI-описания должны проходить проверку перед публикацией.

## Технологии

По структуре репозитория используются HTML, CSS, JavaScript и PHP

- HTML5
- CSS3
- JavaScript
- PHP
- GitHub Pages для публикации статической части сайта

## Структура проекта

- `admin/` — административная часть.
- `catalog/` — каталог продукции.
- `cart/` — корзина.
- `product/` — страницы товаров.
- `css/` — стили интерфейса.
- `js/` — клиентская логика.
- `data/` — данные проекта.
- `img/` — изображения.
- `index.html` — главная страница.
- `mail.php` — PHP-обработчик почтовых операций.
